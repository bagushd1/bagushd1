## 👋 About Me

I am a Software Engineer focused on building high-performance backend microservices, resilient financial integrations, and modern full-stack web and mobile applications.

My background covers **microservices architecture in Go**, **enterprise web platforms with Laravel and Next.js**, **cross-platform mobile clients with Flutter**, and **containerized deployments**. I specialize in creating reliable, decoupled systems designed for high uptime and strict business compliance.

- ⚙️ **Backend & Microservices**: High-concurrency services, transactional synchronization, REST APIs.
- 💻 **Web Platforms**: Scalable enterprise dashboards, responsive UIs, and robust administrative engines.
- 📱 **Mobile Development**: Cross-platform mobile applications with Flutter & Dart.
- 🔒 **Data & Compliance**: Experienced in handling mission-critical workflows with strict data confidentiality standards.
